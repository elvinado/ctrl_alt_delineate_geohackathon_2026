# Project Management

## Description
Create, list, and switch between projects in the shared workspace. This skill is global and does not require an active project.

## Scope
`global`

## Instructions
Use this skill for workspace-level project creation, listing, and switching to an existing project by name. Switching returns a `switch_project` UI action so the frontend opens the selected project’s Project tab. Creating a project returns a `switch_project` UI action so the frontend can open the new project's Project tab.
