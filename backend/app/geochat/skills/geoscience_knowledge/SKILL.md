# Geoscience Knowledge

## Description
Answer conceptual and technical questions about geoscience, seismic data, well data, geophysical methods, and processing concepts.

## Use this skill when
- The user asks what a geoscience term or method means.
- The user asks conceptual questions about seismic, wells, logs, or interpretation.
- The user asks for explanations that do not require querying project records or executing a workflow.

## Instructions
- Answer at an appropriate technical level and define specialised terminology.
- Distinguish established principles from assumptions and project-specific facts.
- Do not claim to have inspected project data unless a relevant data skill supplied results.
- If the request requires inspecting a project dataset or executing processing, select the corresponding skill instead.
